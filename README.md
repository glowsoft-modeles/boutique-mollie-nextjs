# Boutique Mollie Next.js

Un catalogue, un panier et le paiement par un prestataire européen.

Modèle de départ Bastide (`boutique-mollie-nextjs`), écrit par Glowsoft. Il se construit et se déploie sans modification ; la campagne hebdomadaire le construit avec des valeurs d'essai.

## Variables

Le déploiement en un clic les demande avant la construction ; copiez `.env.example` pour un essai local.

- `MOLLIE_API_KEY` (requise) : La clé d'API Mollie, en mode test pour commencer. À obtenir ici : https://my.mollie.com/dashboard/developers/api-keys
